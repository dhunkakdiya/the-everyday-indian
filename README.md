# The Everyday Indian

React + Vite interactive Digital Humanities experience.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

The project uses the embedded SVG artwork in `src/App.jsx` and Three.js for the interactive object views. Tailwind utility classes are loaded through the browser CDN in `index.html`.
